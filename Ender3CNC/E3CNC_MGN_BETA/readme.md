# CAD upload of the E3CNC MGN12H BETA versions

### Note! These are VERY VERY BETA CAD's, they have yet to been tested, if you want to build one you are free too, any issues found and reported would be very helpfull.

## Cheaper version, using MGN12H and belted setup, very close to the original E3CNC.
